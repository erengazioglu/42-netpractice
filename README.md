# Netpractice

## Description

**net_practice** is a project consisting of a series of networking challenges. 10 levels of such exercises are presented in a web-based UI served locally, acting as a basis to discover the basics of IPv4 computer networking, covering notions such as (and not limited to):

- IPv4 addresses,
- URLs,
- switches,
- routers and gateways,
- subnetting,
- the internet.

## Instructions

- Run `tar -xvf net_practice.1.9.tgz` to unpack the subject matter.
- Run `cd net_practice && ./run.sh` to start the server. It will automatically launch the browser.
- Follow the instructions on the program!

The solutions 1-10 submitted in this repository are files generated by the program: after an exercise is solved, the `Get my config` button will export the current state as a JSON file.

### Submission requirements

10 config files (one per level), exported via the `Get my config` button inside the `net_practice` UI, must be present at the root of the repository, and represent valid solutions to the exercises that correspond to the intranet username (in my case, `egaziogl`).

### Networking concepts studied

- **TCP/IP addressing (in IPv4):** what they look like and how they work (32 bits).
- **Subnet masks:** what they represent (network bits vs host bits), what the different values mean (representation in binary).
- **Networks:** given an IP address and a subnet mask, calculating the network, the broadcast, and available host IPs.
- **Routing:** how to set up a network so that the packets travel in the right directions, and using `default`.
